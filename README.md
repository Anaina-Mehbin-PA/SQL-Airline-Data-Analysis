# ✈️ Airline Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analysing airline-related data using MySQL. It explores passenger information, airport details, flight operations, bookings and payment records through SQL queries.

The project demonstrates the application of SQL concepts to retrieve, filter, aggregate and analyse relational data.

## 🛠️ Tools & Technologies

- MySQL
- SQL

## 🗄️ Database Structure

The database consists of five relational tables:

| Table      | Description                                     |
| ---------- | ----------------------------------------------- |
| Passengers | Passenger details, age, gender and location     |
| Airports   | Airport codes, names and locations              |
| Flights    | Flight numbers, airlines, schedules and status  |
| Bookings   | Passenger bookings, seat class and ticket fares |
| Payments   | Payment dates, methods, amounts and statuses    |

## 🔍 SQL Concepts Used

- Data retrieval using SELECT
- Filtering using WHERE
- Sorting using ORDER BY
- DISTINCT
- Aggregate functions (COUNT, SUM, AVG)
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN and RIGHT JOIN
- UNION
- Subqueries
- Pattern matching using LIKE
- Primary keys and foreign key relationships

## 📊 Analysis Performed

The project includes 20 SQL queries covering:

- Passenger details and demographics
- Passenger counts by country
- Average passenger age
- Total bookings by country
- Airline-wise ticket fare analysis
- Confirmed booking counts
- Passenger and flight booking analysis
- Identification of passengers and flights without bookings
- Airport and flight relationships
- Passenger payment analysis
- Passengers booking flights from their own cities
- Airline-wise booking and revenue comparisons
